# Interfaz Gráfica y Visualización (GUI)

Esta carpeta contendrá la interfaz gráfica de usuario encargada de interactuar con las distintas implementaciones de Huffman (Serial, Pthreads y Fork) y generar visualizaciones comparativas.

## Objetivos del módulo
- Interfaz gráfica para seleccionar archivos o directorios a comprimir/descomprimir.
- Selección del modo de ejecución (Serial, Pthreads o Fork) y configuración de parámetros (por ejemplo, número de hilos o procesos).
- Generación y presentación de gráficas comparativas de rendimiento:
  - Tiempo de ejecución vs. tamaño de archivo o número de hilos/procesos.
  - Métricas de aceleración (*speedup*) y eficiencia.
  - Tasa de compresión y validación de integridad MD5.
